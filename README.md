# Plant Doctor AI

AI-powered plant disease detection using TensorFlow, MobileNetV2, and Streamlit.

## Features
- Tomato, Potato, and Bell Pepper disease prediction.
- Prediction confidence and top-3 results.
- Plant care recommendations.

## Model Performance
Validation accuracy: 92.71%. Real-world performance may differ.

## Run Locally
1. Install Python 3.12.
2. Run: python -m pip install -r requirements.txt
3. Run: python -m streamlit run main.py
